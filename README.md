## 🎯 Возможности

- Встроенный движок Stockfish 15+

- Оценка ошибок (блунды, оши��ки, неточности)

- Красивая статистика ваших побед/поражений/ничьих

### 🧠 AI Тренер - Система Обучения
Полный курс от новичка до мастера:
- **Основы дебюта** - Контроль центра, развитие фигур, безопасность короля
- **Тактика для начинающих** - Вилки, булавки, связки
- **Стратегия миттельшпиля** - Слабые поля, структура пешек
- **Техника эндшпиля** - Король и пешка, ладейные окончания
- **Анализ своих игр** - Разбор ошибок и улучшение
- **Психология игры** - Управление стрессом, тайм-менеджмент

Каждый урок включает:
- 📖 Подробную теорию с диаграммами
- 🎬 Примеры из партий гроссмейстеров
- 💪 Практические упражнения
- ❓ Квиз для проверки знаний

## 🚀 Быстрый Старт

### Требования
- Node.js 18+
- npm или yarn
- Современный браузер

### Установка

```bash
# Клонируйте репозиторий
git clone https://github.com/sabdanovelaman-eng/chess-master-pro.git
cd chess-master-pro

# Установите зависимости
npm install

# Создайте .env файл
cp .env.example .env

# Запустите разработческий сервер
npm run dev
```

Сайт будет доступен на `http://localhost:3000`

## 🎮 Использование

### 1. Подключение Chess.com
1. Откройте приложение
2. Введите ваш username с Chess.com
3. Нажмите "Подключить"
4. Все ваши партии и статистика загрузятся автоматически

### 2. Анализ Партии
1. Перейдите на вкладку "Анализ"
2. Вставьте PGN вашей партии
3. Нажмите "Анализировать"
4. Получите рекомендации от Stockfish

### 3. Решение Задач

3. Решайте практические задачи

5. Получайте сертификат при завершении

## 🔧 Конфигурация

Отредактируйте `.env` файл для настройки:

```env
# Chess.com API
VITE_CHESS_COM_API_KEY=your_api_key

# API URL
VITE_API_URL=http://localhost:3000/api

# Stockfish путь
VITE_STOCKFISH_PATH=/stockfish/stockfish.wasm
```

## 📝 API Интеграция Chess.com

Приложение использует публичный API Chess.com:

```javascript
// Получить профиль
GET /pub/player/{username}

// Получить партии
GET /pub/player/{username}/games

// Получить статистику
GET /pub/player/{username}/stats
```

Полная документация: https://www.chess.com/news/view/published-data-api

## 🎓 Примеры Использования

### Подключение аккаунта
```typescript
import { chesscomApi } from '@/services/chesscomApi'

const profile = await chesscomApi.getProfile('username')
console.log(profile.rating) // 1850
```

### Анализ позиции
```typescript
import { stockfishEngine } from '@/services/stockfishEngine'

await stockfishEngine.init()
const analysis = await stockfishEngine.analyze(
  'rnbqkbnr/pppppppp/8/8/8/8/PPPPPPPP/RNBQKBNR w KQkq - 0 1',
  20 // глубина анализа
)
console.log(analysis.bestMove) // e2e4
```
